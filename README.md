# COMPACTORE

**A Product Price Comparison Android Application**

COMPACTORE is an Android application designed to help users discover products and compare prices, making online shopping easier and more convenient.

### Features
- User authentication
- Home screen with featured products
- Product categories
- Product details
- Hot deals section
- User profile

### Technologies Used
- Kotlin
- XML
- Android Studio
- Firebase
- Cloud Firestore

### Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Configure Firebase by adding your `google-services.json` file inside the `app` directory.
4. Sync Gradle.
5. Run the application.
